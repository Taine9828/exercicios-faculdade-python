# 🐍 Exercícios de Python – Ciência da Computação

Este repositório reúne exercícios e atividades desenvolvidos durante meus estudos de Python no curso de Ciência da Computação.

O objetivo é praticar e desenvolver conhecimentos em lógica de programação, estruturas condicionais, estruturas de repetição, manipulação de dados e conceitos fundamentais da linguagem Python.

## 📚 Conteúdos estudados

Os exercícios estão organizados em arquivos individuais, de acordo com os assuntos praticados:

| Arquivo | Conteúdo |
|---|---|
| `AnteSuce.py` | Antecessor e sucessor de um número |
| `aprovado_reprovado.py` | Verificação de aprovação ou reprovação |
| `calcula_media.py` | Cálculo de média |
| `contagem.py` | Exercício de contagem |
| `maior_numero.py` | Comparação entre números |
| `nome_idade.py` | Entrada e exibição de nome e idade |
| `par_impar.py` | Identificação de números pares e ímpares |
| `soma_numeros.py` | Soma de números |
| `While.py` | Estrutura de repetição while |
| `teste_api.py` | Prática envolvendo consumo de API |

## 🛠️ Tecnologias utilizadas

- Python
- Visual Studio Code
- Git
- GitHub

## ▶️ Como executar os exercícios

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Certifique-se de ter o Python instalado.
4. Escolha o arquivo que deseja executar.
5. Execute o código pelo terminal ou pelo próprio VS Code.

Exemplo:

```bash
python maior_numero.py
```

Este repositório faz parte da minha jornada de aprendizado em Ciência da Computação.

Os exercícios são desenvolvidos com o propósito de fortalecer a lógica de programação, praticar a linguagem Python e acompanhar minha evolução na área de tecnologia.
